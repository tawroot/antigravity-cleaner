Smart SOCKS5 Proxy Injection (One-Time Temporary Connect)

Cleaner eliminates the friction of configuring proxy settings or running CPU-intensive system-wide TUN adapters:

Zero-Configuration & Turn Off VPN After Launch

1. Zero Manual IP/Port Setup: Cleaner automatically detects your local proxy client (v2rayN, Nekoray, Clash, Sing-box) on standard SOCKS5 ports (10808 / 7890).
2. Connect Once & Turn Off: Simply launch your proxy client, click [Launch IDE] (or run ag-cleaner launch), and once Antigravity establishes connection, you can safely turn off your VPN/proxy completely! The IDE maintains its authorized stream and works stably without keeping a VPN running in the background.
3. Only Reconnect If Dropped: Only in the rare event that your network node drops will you need to briefly enable the proxy again to re-authenticate.
4. Traditional VPNs: Full-tunnel VPNs (like Windscribe) that route the entire operating system require zero extra configuration.

Real-World Error Troubleshooting Clinic

Diagnoses and instant surgical fixes for the 5 most common failure modes encountered by Antigravity developers:

Error 01: Agent Terminated Due to Error (write EIO / Pipe Failure)

Quote: "Agent terminated due to error. You can prompt the model to try again..."
Cause: Sudden pipe breakdown caused by verbose raw logging (write EIO) or middlebox TCP connection timeouts during long reasoning chains.
Fix: Click [Auto-Fix]. The ASAR Zero-Log Shield silences broken pipe exceptions and injects 15s TCP KeepAlive heartbeat socket tuning.

Error 02: Network Issue Connecting to Server (DPI Severance)

Quote: "There was a network issue connecting to the server, please try again. Error ID: 95ea05dd..."
Cause: Deep Packet Inspection (DPI) firewalls dropping idle gRPC streams or telemetry probes exposing real IP midway through conversation.
Fix: Launch with ag-cleaner launch (or GUI Launch IDE). Isolates streams over direct SOCKS5h socket with zero telemetry exfiltration.

Error 03: Authentication Gating / 403 Forbidden (/auth-success)

Quote: "Google 403. That's an error. Your client does not have permission to get URL /auth-success..."
Cause: Google regional check flagging browser login redirect from sanctioned regions.
Fix: Run [Auto-Fix]. Sets hasValidAuth = true, passes enterprise stubby flags, and clears poisoned auth tokens.

Error 04: Proxy Connection Refused (dial tcp 127.0.0.1:10808)

Quote: "proxyconnect tcp: dial tcp 127.0.0.1:10808: connect: connection refused"
Cause: Local proxy client (Xray, Clash, Sing-box, NekoBox) is closed or listening on a different port (e.g. 7890 / 2080).
Fix: Run ag-cleaner doctor. Automatically scans open local proxy ports and re-configures IDE routing instantly.

Frequently Asked Questions

Is Antigravity Cleaner safe to run on my system?

Yes. 100% auditable open-source code under Apache 2.0. Cleaner runs completely locally on 127.0.0.1 with zero internet access required during patching. It contains no shady DLLs, no telemetry beacons, and passes continuous GitHub CodeQL and Govulncheck automated security audits.

Will running Cleaner wipe my conversation history or project workspaces?

Zero Chat Loss Guarantee. سپر حریم خصوصی و قطع کامل تله‌متری

در نسخه خام Antigravity، صدها درخواست زمینه‌ای به سرورهای تله‌متری گوگل فرستاده می‌شود که حاوی پرامپت‌ها، ساختار پروژه‌ها، هش کامیت‌های گیت و شناسه‌های آی‌پی کاربر است. ابزار Cleaner با اعمال ۸ فلگ ایزولاسیون شرکتی، ارتباط با تمامی دامنه‌های تله‌متری زیر را مسدود می‌سازد:

دامنه‌های مسدودشده توسط شیلد حریم خصوصی

telemetry.googleapis.com • crashlytics.google.com • vortex.data.google.com • play.googleapis.com/log • firebaselogging-pa.googleapis.com

تزریق هوشمند پروکسی محلی (بدون نیاز به مود TUN)

فعال‌سازی مود TUN در فیلترشکن‌ها باعث هدایت تمامی ترافیک سیستم، کندی شدید سرعت، مصرف بالای باتری و قطع اتصال سایر برنامه‌ها می‌شود. Cleaner با تزریق مستقیم فلگ‌های شبکه، تنها ترافیک موتور Antigravity را از طریق پورت محلی هدایت می‌کند:

نحوه استفاده با کلاینت‌های محبوب

کافیست کلاینت پروکسی محلی خود (v2rayN پورت ۱۰۸۰۸، نکورای ۱۰۸۰۸ یا کلش ۷۸۹۰) را اجرا کنید. ابزار به طور هوشمند پورت فعال را پیدا کرده و با آن متصل می‌شود. پس از اتصال، می‌توانید پروکسی را خاموش کنید تا IDE پایدار و بدون ایجاد ترافیک اضافه روی سیستم کار کند.

بازگشت سریع به تنظیمات دست‌نخورده کارخانه (.agybak)

امنیت سیستم شما اولویت اول ماست. ابزار پیش از اعمال هرگونه تغییر بر روی حتی یک بایت از فایل‌های هسته، یک نسخه پشتیبان تمیز با پسوند .agybak در کنار فایل اصلی ذخیره می‌کند:

bash 
# Revert all patched binaries back to pristine factory state
antigravity-cleaner --rollback

کلینیک تخصصی رفع ۵ خطای رایج Antigravity

تحلیل فنی و راه‌حل قطعی تمامی ارورهایی که توسعه‌دهندگان با آن مواجه می‌شوند:

Error 1

خطای قطع ناگهانی و قفل شدن ایجنت حین فکر کردن (write EIO)

علت فنی: تلاش موتور الکترون برای نوشتن لاگ‌های حجیم تله‌متری روی پایپ استاندارد کنسول که در صورت پر شدن یا قطع سوکت باعث کرش جریان پردازش می‌شود.

راه‌حل با Cleaner: تزریق شیلد بدون لاگ ASAR؛ این پچ کدهای ارسال لاگ زاید را بی‌صدا کرده و با ایجاد هندلر خطای سوکت، مانع از کرش کردن ایجنت می‌شود.

Error 2

خطای شبکه و شکست دست‌دادن TLS (Network Issue / Handshake Failure)

علت فنی: تداخل سیستم فایروال یا بازرسی بسته‌های اینترنت با ارتباط امن TLS بین کلاینت و سرورهای هوش مصنوعی گوگل.

راه‌حل با Cleaner: کلیک روی دکمه [Launch IDE] جهت اتصال خودکار از طریق پروکسی سالم لوکال بدون نشت ترافیک DNS.

Error 3

خطای عدم دسترسی در کشور شما (Error 403 Forbidden / Not Available)

علت فنی: چک سخت‌گیرانه گوگل بر روی کدهای باینری ماشین موتور اصلی و خواندن کدهای منطقه‌ای IP.

راه‌حل با Cleaner: اجرای گزینه [Auto-Fix] در رابط گرافیکی یا اجرای دستور antigravity-cleaner --force جهت پچ دائمی شرط احراز هویت.

Error 4

خطای رد اتصال به پورت پروکسی (ECONNREFUSED 127.0.0.1:10808)

علت فنی: کلاینت پروکسی سیستم (مانند v2rayN یا Nekoray) بسته است یا پورت لوکال فعال روی پورت دیگری (مثل ۷۸۹۰ کلش) تنظیم شده است.

راه‌حل با Cleaner: کلاینت فیلترشکن خود را باز کنید یا دستور antigravity-cleaner --doctor را اجرا نمایید تا پورت صحیح شناسایی شود.

Error 5

خطای اتمام سهمیه یا لیمیت کاذب (Error 429 Too Many Requests)

علت فنی: ذخیره کوکی‌های خراب و باکت‌های محدودیت توکن در دیتابیس لوکال DIPS مرورگر الکترون که پس از تعویض آی‌پی ریست نمی‌شوند.

راه‌حل با Cleaner: اجرای دستور antigravity-cleaner --clean جهت پاکسازی جراحی ۱۶ فایل سشن در ۲ میلی‌ثانیه با حفظ ۱۰۰٪ تاریخچه چت‌ها.

سوالات متداول و امنیت

آیا استفاده از Antigravity Cleaner برای سیستم من کاملاً امن است؟

بله، ۱۰۰٪ متن‌باز و قابل بررسی تحت مجوز رسمی Apache 2.0. ابزار کاملاً بر روی آدرس محلی 127.0.0.1 اجرا شده و در حین اعمال پچ‌ها نیازی به اینترنت ندارد. فاقد هرگونه فایل DLL خارجی یا تله‌متری پنهان بوده و تمامی ممیزی‌های امنیتی خودکار GitHub CodeQL و Govulncheck را با موفقیت پشت سر گذاشته است.

آیا اجرای Cleaner باعث پاک شدن تاریخچه چت‌ها یا پروژه‌های من می‌شود؟

تضمین حفظ ۱۰۰٪ تاریخچه چت‌ها (Zero Chat Loss). برخلاف اسکریپت‌های غیررسمی دیگر که کل پوشه globalStorage را به صورت مخرب پاک می‌کنند، متد جراحی Cleaner صرفاً ۱۶ کوکی مسموم‌شده مربوط به لیمیت سهمیه را پاکسازی می‌کند. تاریخچه چت‌ها، فایل‌های پروژه و سشن لاگین شما کاملاً دست‌نخورده باقی می‌ماند.
