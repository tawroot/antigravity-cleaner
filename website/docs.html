Quick Start Guide

📥 Installation

Windows

Download the portable EXE - no installation required!

Download for Windows

macOS / Linux

curl -sSL https://raw.githubusercontent.com/tawroot/antigravity-cleaner/main/install.sh | bash

Windows PowerShell

iwr -useb https://raw.githubusercontent.com/tawroot/antigravity-cleaner/main/install.ps1 | iex

How to Use

1️⃣

Launch Application

Run the downloaded executable. On first launch, you'll see the Dashboard with your system health score.

2️⃣

Analyze System

Click "Analyze Now" to scan for Antigravity traces, leftover files, and browser sessions. This is 100% safe - read-only scan.

3️⃣

Backup Sessions

Go to Sessions tab, select browser profiles, and click Backup. Your sessions are encrypted and stored locally.

4️⃣

Test Google Connectivity

Use the "Google Test" page to diagnose access to Google Account, Gemini AI, and Cloud services.

5️⃣

Clean System

Go to Cleaner tab. Choose Quick Clean or Deep Clean. Review changes before confirming.

6️⃣

Network Tools

Use Network tab to flush DNS, reset network stack, or run diagnostics to fix connection issues.
