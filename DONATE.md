# ☕ Support & Donations

**Antigravity Cleaner** is and will always remain **100% free, offline, and open-source** under the [Apache-2.0 License](LICENSE).

It has helped thousands of developers across Cuba, Iran, Russia, China, the US, Europe, and worldwide bypass regional locks and overcome Error 403 & 429 barriers.

Supporting this project is **completely optional**. If this tool has saved you time or helped you use Google Antigravity seamlessly, any contribution is warmly appreciated and directly helps support:
- Testing infrastructure across diverse Linux, macOS, and Windows environments
- Reverse-engineering maintenance for new Google Antigravity IDE and CLI releases
- Dedicated proxy and middlebox testing relays
