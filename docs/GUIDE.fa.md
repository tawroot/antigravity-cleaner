## 🎯 مشکلاتی که این ابزار حل می‌کند

| عنوان خطا / مشکل | دلیل فنی وقوع | راه‌حل آنتی‌گراویتی کلینر |
| :--- | :--- | :--- |
| **`User location is not supported` (خطای ۴۰۳)** | بررسی سخت‌گیرانه بایت‌کد `language_server` برای احراز کشور و ریجن کاربر. | **`ag-cleaner patch`**: اسکن فوق‌سریع بایت‌کد و غیرفعال‌سازی بررسی موقعیت جغرافیایی. |
| **`Quota exceeded / Rate limited` (خطای ۴۲۹)** | قفل شدن کش نشست‌های محلی و فایل‌های PID یتیم که سیستم را به اشتباه در وضعیت لیمیت نگه می‌دارد. | **`ag-cleaner clean`**: پاکسازی جراحی و ایزوله کش سهمیه بدون لمس کدهای پروژه‌ها یا تنظیمات. |
| **فریز شدن تولید پاسخ در ۹۹٪** | قطعی اتصالات سوکت به دلیل عدم وجود ارسال دوره‌ای پینگ در فایروال‌های میانی اینترنت. | **`ag-cleaner proxy`**: فعال‌سازی هارت‌بیت فعال TCP KeepAlive جهت حفظ پایداری ارتباط. |
| **کار کردن فیلترشکن در مرورگر اما کار نکردن در ادیتور** | ادیتور به صورت یک دیمن مستقل اجرا می‌شود و تنظیمات پروکسی ویندوز/سیستم را دور می‌زند. | **`ag-cleaner proxy`**: هدایت مستقیم سوکت‌های شبکه به پورت‌های لوکال (۱۰۸۰۸ یا ۷۸۹۰) بدون نیاز به VPN سیستمی. |

## 🖥️ روش‌های اجرای برنامه

### ۱. رابط گرافیکی نوستالژیک Retro KeyGen
* **مناسب برای:** کاربرانی که می‌خواهند بدون وارد کردن دستورات ترمینال، با یک کلیک مشکل را حل کنند.
* **نحوه اجرا:** فایل دانلود شده از بخش Releases را اجرا کنید (روی ویندوز دابل‌کلیک روی `.exe`).
* **امکانات:** ظاهر کلاسیک ویندوز ۹۵، پس‌زمینه ستاره‌ای متحرک، افکت‌های صوتی رترو، دکمه جادویی **"Auto-Fix & Patch"**.

### ۲. داشبورد تعاملی ترمینال (TUI)
* **مناسب برای:** برنامه‌نویسانی که محیط ترمینال تعاملی را می‌پسندند.
* **دستور اجرا:**
  ```bash
  ag-cleaner tui
  ```
* **کلیدهای میانبر:** کلید `Tab` برای جابجایی بین پنل‌ها، `Enter` برای اجرای عملیات و `q` برای خروج.

### ۳. دستورات خط فرمان ترمینال (CLI)
* **مناسب برای:** اسکریپت‌ها، اتوماسیون و کاربران حرفه‌ای.

## 🛠️ مرجع کامل دستورات CLI

### `ag-cleaner doctor`
تست جامع سلامت، اتصالات و وضعیت فایل‌های محیط آنتی‌گراویتی.
```bash
ag-cleaner doctor
```
**موارد مورد بررسی:**
* بررسی وضعیت پروسه‌های در حال اجرای ادیتور و موتور `language_server`.
* بررسی دسترسی به پورت‌های سوکت داخلی gRPC.
* تست پینگ و دسترسی به سرورهای گوگل کلود (`cloudcode.googleapis.com`).
* بررسی متغیرهای محیطی پروکسی در سیستم.
* بررسی وضعیت پچ بودن باینری (پچ‌شده یا دست‌نخورده).

---

### `ag-cleaner clean`
پاکسازی جراحی و هدفمند کش‌های فاسد و فایل‌های قفل مانده.
```bash
ag-cleaner clean
```
**موارد پاکسازی:**
* فایل‌های قفل یتیم (`.lock` و `.pid`) که مانع اجرای موتور هوش مصنوعی می‌شوند.
* کش خراب ریت‌لیمیت و شمارنده‌های سهمیه (خطای ۴۲۹).
* سوکت‌های قطع‌شده IPC.

> [!IMPORTANT]
> دستور `clean` **به هیچ وجه** کدهای پروژه، ریپازیتوری‌های گیت، اکستنشن‌ها یا کلیدهای میانبر شما را حذف نمی‌کند. این عملیات ۱۰۰٪ غیرتخریبی و ایمن است.

---

### `ag-cleaner patch`
اعمال پچ مستقیم بایت‌کد روی موتور `language_server` جهت خنثی‌سازی تحریم و چک موقعیت جغرافیایی.
```bash
ag-cleaner patch
```
* شناسایی خودکار مسیر نصب آنتی‌گراویتی در سیستم‌عامل شما.
* ایجاد بکاپ خودکار و تاریخ‌دار از فایل اصلی (`language_server.bak.<timestamp>`).
* اعمال الگوریتم بایر-مور برای تشخیص و اصلاح شرط اعتبارسنجی کشور.

جهت بازگرداندن فایل اصلی و لغو پچ:
```bash
ag-cleaner patch --restore
```

---

### `ag-cleaner proxy`
پیکربندی و تزریق مسیر مستقیم پروکسی بدون نیاز به روشن کردن حالت سنگین TUN.
```bash
# تشخیص خودکار پورت‌های رایج (10808, 7890, 1080, 2080)
ag-cleaner proxy

# مشخص کردن پورت ساکس ۵ دلخواه
ag-cleaner proxy --socks5 127.0.0.1:10808

# مشخص کردن پورت HTTP دلخواه
ag-cleaner proxy --http 127.0.0.1:7890
```

---

### `ag-cleaner run`
اجرای محیط ادیتور در بستری کنترل‌شده با تزریق امن متغیرهای شبکه.
```bash
ag-cleaner run
```

## 🚀 سناریوهای حل مشکل گام‌به‌گام

### سناریوی ۱: رفع خطای محدودیت منطقه‌ای و تحریم (۴۰۳)
1. برنامه Antigravity IDE را کاملاً ببندید.
2. دستور پچ را در ترمینال اجرا کنید:
   ```bash
   ag-cleaner patch
   ```
3. وضعیت را با دستور پزشک بررسی کنید:
   ```bash
   ag-cleaner doctor
   ```
4. فیلترشکن خود را فعال کرده و ادیتور را باز کنید. تمام پیام‌های عدم پشتیبانی از منطقه جغرافیایی برطرف خواهند شد.

---

### سناریوی ۲: رفع خطای سقف سهمیه و قفل ریت‌لیمیت (۴۲۹)
1. ادیتور را ببندید.
2. پاکسازی جراحی را اجرا کنید:
   ```bash
   ag-cleaner clean
   ```
3. مجدداً ادیتور را اجرا نمایید؛ شمارنده‌های کاذب ریست شده و درخواست‌های چت و کد باز خواهند شد.

---

### سناریوی ۳: رفع قطعی استریم پاسخ و تایم‌اوت
1. از سلامت سرور پروکسی خود اطمینان حاصل کنید.
2. ادیتور را با نگهدارنده فعال سوکت اجرا کنید:
   ```bash
   ag-cleaner run
   ```

---

### سناریوی ۴: اتصال از طریق پروکسی لوکال بدون نیاز به حالت سنگین TUN
اگر مایل به فعال‌سازی حالت VPN / TUN روی کل سیستم نیستید:
1. نرم‌افزار پروکسی خود (کلش روی ۷۸۹۰ یا ویتوری روی ۱۰۸۰۸) را باز نگه دارید.
2. دستور زیر را بزنید:
   ```bash
   ag-cleaner proxy --socks5 127.0.0.1:10808
   ```
3. ادیتور مستقیماً و با کمترین تاخیر به پورت لوکال متصل می‌شود.

## 🛡️ امنیت، بکاپ و بازگردانی نسخه اصلی

با هر بار اجرای `ag-cleaner patch`، یک کپی دست‌نخورده از فایل اصلی با نام زیر در کنار آن نگهداری می‌شود:
- **الگوی نام‌گذاری:** `<original_binary>.bak.<timestamp>`
- **دستور بازگردانی آنی:**
  ```bash
  ag-cleaner patch --restore
  ```
