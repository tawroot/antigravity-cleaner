### ۲. رپر شفاف تزریق پرچم‌های سازمانی (Process Wrapper)
* **مسیر فایل رپر فعال:**  
  `/home/hokar/Applications/Antigravity/resources/bin/language_server`
* **نوع فایل:** اسکریپت Bash اجرایی که جایگزین نام اصلی باینری شده و کنترل پروسه را در دست دارد.
* **محتوای خط اجرای رپر:**
  ```bash
  #!/usr/bin/env bash
  DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
  exec "$DIR/language_server.bin" \
    --disable_telemetry=true \
    --is_google_internal=true \
    --jetbox_release_channel=insiders \
    --stubby_auth_mode=business_licensed_enterprise \
    --use_local_chrome=true \
    --browser_eval_env=true \
    --local_chrome_headless=false \
    "$@"
  ```
* **تحلیل عملکرد تک‌تک فلگ‌های تزریق‌شده:**
  1. `--disable_telemetry=true`: تنظیم فیلد پروتوباف `disableTelemetry: true` در تمام درخواست‌های `GetChatMessageRequest`؛ قطع ۱۰۰٪ ارسال لاگ‌های ترمینال، لاگ‌های گیت و خطاهای ران‌تایم (`UploadErrorTraces`) به سرورهای تله‌متری گوگل.
  2. `--is_google_internal=true`: باز شدن شاخه منطقی مهندسان داخلی؛ طبق شواهد لاگ، اجرای کد `Skipping retroactive projects migration: only runs for external users` و دور زدن بلک‌لیست آدرس‌های محلی (`CheckUrlDenylist`).
  3. `--jetbox_release_channel=insiders`: اتصال به کانال زودهنگام پایلوت‌های گوگل.
  4. `--stubby_auth_mode=business_licensed_enterprise`: ارسال هدرهای احراز هویت تحت ساختار تجاری گوگل.
  5. `--use_local_chrome=true --browser_eval_env=true --local_chrome_headless=false`: فعال‌سازی محیط ارزیابی کروم لوکال طبق لاگ صریح `launchmanager.go:69: Entering local chrome mode!` و اتصال مستقیم به مرورگر `/usr/bin/google-chrome` سیستم، همراه با باز شدن پورت دیباگ DevTools (پورت‌های رنج ۴۰۰۰۰ و وب‌سوکت CDP).

### ۳. درگاه مخفی اتصال مدل‌های دلخواه (BYOM - Bring Your Own Model)
* **آفست بایت‌کد در باینری:** `0x40ddbe3`
* **ساختار پروتوباف استخراج‌شده:**
  ```protobuf
  message UnifiedStateSync {
    UserSettings userSettings = 1;
    // ...
  }

  message CustomModels {
    map<string, ModelInfo> customModels = 1;
  }
  ```
* **فیلدهای شیء `ModelInfo`:**
  - `BaseUrl`: آدرس ریموت یا لوکال اندپوینت مدل (مثلاً `http://127.0.0.1:8000/v1` برای 9router یا Ollama).
  - `ModelName`: نام مدل ارسالی در درخواست (مانند `claude-3-7-sonnet` یا `deepseek-r1`).
  - `DisplayName`: نام نمایشی داخل رابط کاربری.
  - `MaxTokens` و `ThinkingBudget`: تنظیم بودجه تفکر مدل.
  - پروتکل‌های ثبت‌شده: `MODEL_OPENAI_COMPATIBLE` و `MODEL_CUSTOM_OPEN_ROUTER`.
* **اهمیت این یافته:**  
  این قابلیت در رابط کاربری عمومی کلاینت پنهان است و مهندسان برای اتصال خوشه‌های vLLM یا تست‌های تطبیقی آن را تعبیه کرده‌اند. فعال‌سازی این پروتکل به کاربر اجازه می‌دهد بدون نیاز به سرورهای گوگل، کلاینت را به 9router یا هر ارائه‌دهنده دیگر متصل کند.

### ۷. کالبدشکافی هویت `is_google_internal=true` در سطح اسمبلی
با تحلیل دستورات ماشین در آفست `0x6d1b142` و بررسی نمادهای هسته `google3/third_party/jetski`، مشخص شد که فعال شدن پرچم مهندسان داخلی، این ۵ دسترسی عینی و عملی را ایجاد می‌کند:

1. **بای‌پاس اعتبارسنجی آدرس‌های تحت شبکه (`CheckUrlDenylist`):**  
   کلاینت در حالت کاربر عادی، آدرس‌های محلی و پورت‌های سفارشی را مسدود می‌کند. با فعال بودن هویت داخلی، این تابع بای‌پاس شده و اجازه ارتباط با سرورهای لوکال و پورت‌های دلخواه داده می‌شود.
2. **بازگشایی انوم و متد اختصاصی BYOM (`MODEL_GOOGLE_GEMINI_INTERNAL_BYOM` با کد ۳۲۶ و `WithAllowBYOM`):**  
   کلید اصلی درگاه مدل‌های دلخواه در پکیج `models/model_config.WithAllowBYOM` وابسته به پرچم‌های دسترسی سازمانی است.
3. **فعال‌سازی سیستم فایل رقابت مدل‌ها (BattleModeFS):**  
   دسترسی به توابع `NewBattleModeFS` و الگوریتم حذفی `EliminateBattleModeArm` برای مسابقه دو مدل هم‌زمان روی شاخه‌های گیت.
4. **حالت ارزیابی لوکال کروم (`launchmanager.go:69`):**  
   دور زدن تب‌های شبیه‌ساز ابری و سوئیچ مستقیم به باینری `/usr/bin/google-chrome` سیستم همراه با اکسپوز شدن پورت DevTools CDP.
5. **توقف کامل مهاجرت‌های اجباری (`Skipping retroactive projects migration`):**  
   حذف پایش‌های دسترسی اکانت‌های عمومی و مهار گزارش‌های اخطار.

### ۸. تفکیک دقیق: پروژه جارویس در برابر نام مدل

  - `MODEL_GOOGLE_GEMINI_COMPUTER_USE_EXPERIMENTAL`
* **نام مدل دقیق عملیاتی:** `gemini-v4s-jarvis-sc`

  - **`sc`:** مخفف **Sidecar** یا **State-Control**؛ مدلی که درون پنل کناری ادیتور قرار گرفته و رویدادهای ماوس (`mouseMoved`)، اسکرول و تعامل با صفحات را تولید می‌کند.

| **شکستن محدودیت آدرس‌های لوکال (`CheckUrlDenylist`)** | ✅ **قطعی (هویت داخلی)** | با فعال‌سازی `is_google_internal` فیلتر آدرس‌های لوکال برای تزریق مدل و دیباگ باز شده است. |
| **دریافت آپدیت‌ها در کانال Insiders** | ✅ **فعال روی کلاینت** | باینری با فلگ کانال آزمایشی اجرا می‌شود و بدون کرش استیبل است. |
| **باز شدن مدل‌های محرمانه جارویس یا آرگون** | ❌ **ردشده (کنترل سمت سرور)** | کلاینت آماده است اما گیت‌وی ابری سرورهای گوگل (`ESF`) توکن‌های اکانت را اعتبارسنجی کرده و ارور `404 NOT_FOUND` می‌دهد. |
| **دور زدن لایسنس سرور با `stubby_auth_mode`** | ❌ **ردشده (کنترل سمت سرور)** | لاگ پروسه صراحتاً ثبت کرد: `SetUserTier called with userTier: ""`. سرور گوگل لایسنس سروری اکانت را تغییر نداده است. |
