## 🌍 Глобальная проблема, которую мы решаем

**Antigravity Cleaner** изначально был разработан для пользователей из Ирана, но проблемы, которые он решает, **универсальны по всему миру**.

### 🎯 Какие проблемы мы решаем:

- **🚫 Региональные ограничения**: Сервисы Google недоступны в некоторых странах из-за санкций (Иран, Куба, Сирия, Северная Корея, Крым)
- **🌐 Сетевое вмешательство**: Манипуляции с DNS, конфликты прокси, ограничения файрвола
- **🔒 Ошибки региональной блокировки**: Сообщение "Недоступно в вашем регионе" при входе
- **📡 Проблемы подключения**: Сетевые ошибки, таймауты, ошибки SSL-сертификатов
- **🔄 Ошибки установки**: Повреждённые загрузки, зависшие процессы, остаточные файлы
- **🔐 Истечение сессии**: Повторные запросы входа, повреждение cookie

### 👥 Кто использует этот инструмент:

- **🚨 Сети с жёсткими ограничениями**: Страны с комплексной интернет-фильтрацией (Китай, Туркменистан, Северная Корея, Иран)
- **⚖️ Санкционные регионы**: Регионы, где сервисы Google официально заблокированы (Иран, Куба, Сирия, Крым)
- **🌐 Частично фильтруемые сети**: Регионы с выборочными ограничениями (Россия, Турция, Египет, Пакистан)
- **🏢 Ограниченные сетевые среды**: Корпоративные сети, образовательные учреждения, публичный WiFi
- **✈️ Путешественники и экспаты**: Пользователи, сталкивающиеся с региональной блокировкой при путешествиях
- **🔧 Разработчики и IT-специалисты**: Системные администраторы для решения проблем установки и сети

---

### 🌟 Комплексные решения универсальных проблем:

**Antigravity Cleaner** предоставляет мощный набор инструментов для преодоления самых раздражающих препятствий для пользователей в ограниченных или нестабильных сетевых средах.

- **🔐 Исправление и оптимизация входа в Google**:
  - Автоматическое исправление распространенных ошибок входа в Google (403 Forbidden, 400 Bad Request), вызванных региональными блокировками.
  - Очистка специфических следов браузера, которые блокируют попытки аутентификации в Google.
  - Оптимизация сетевых настроек специально для обхода прерываний соединения, связанных со входом.

- **🌐 Оптимизация сетевого стека и DNS**:
  - **Очистка и сброс (Flush & Reset)**: Полный сброс сетевого стека (Winsock) и очистка кэша DNS для устранения помех.
  - **Проверка работоспособности DNS**: Определение того, вмешивается ли ваш DNS-провайдер в соединения с сервисами.
  - **Разрешение конфликтов прокси**: Обнаружение и помощь в устранении скрытых настроек прокси, нарушающих работу браузера.

- **💾 Локальное зашифрованное управление сессиями**:
  - **Безопасное извлечение**: Безопасное извлечение сессионных cookie из профилей браузера для переноса или резервного копирования.
  - **Приватность Zero-Cloud**: Все данные хранятся **локально** на вашей машине. **Никакие данные никогда не отправляются на внешние серверы.**
  - **Шифрование AES-256**: Сессии сохраняются с использованием промышленного стандарта шифрования и защищены уникальным мастер-ключом вашей системы.
  - **Переносимость профилей**: Легко переносите аутентифицированные сессии между профилями или устройствами без повторного ввода пароля.

## ✨ Основные функции

### 🧹 Глубокая очистка
- Удаление следов из AppData, Temp, реестра и **расширений Chrome**
- Полная очистка остаточных файлов
- Автоматическое резервное копирование перед удалением

### 🌐 Сброс сети
- Автоматическое выполнение `netsh` и `flushdns`
- Исправление ошибок "Сетевая ошибка" или "Региональная блокировка"
- Обнаружение и исправление проблем DNS

### 🔧 Управление процессами
- Автоматическое завершение зависших процессов
- Обнаружение запущенных сервисов
- Безопасная очистка без потери данных

### 🌐 Помощник входа в браузер (v2.1+)

Проблемы со входом в Antigravity? Эта функция поможет:

**Безопасная очистка браузера:**
- Удаляются только данные, связанные с Antigravity
- Остальные данные браузера остаются нетронутыми
- Автоматическое резервное копирование перед удалением
- Поддержка Chrome, Edge, Brave и Firefox

**Управление сессиями:**
- Резервное копирование сессии после успешного входа
- Восстановление сессии для избежания повторного входа
- Зашифрованное хранение (AES-256)
- Срок действия 30 дней

**Оптимизация сети:**
- Тест подключения к сервисам Google
- Диагностика проблем DNS и прокси
- Исправление проблем SSL-сертификатов
- Подробные диагностические отчёты

## 📋 Полное руководство по функциям

### 1️⃣ Быстрая очистка (Стандартные пути)
**Что делает:**
- Сканирует стандартные папки установки Antigravity
- Удаляет остаточные файлы из AppData и Roaming
- Очищает базовые файлы конфигурации

**Когда использовать:**
- После обычного удаления Antigravity
- Для регулярной очистки
- Когда нужно быстро и безопасно очистить

**Безопасность:** ✅ Очень безопасно - только файлы Antigravity

---

### 2️⃣ Глубокая очистка (Агрессивное сканирование)
**Что делает:**
- Всё из быстрой очистки, плюс:
- Сканирование реестра Windows на записи Antigravity
- Удаление временных файлов установки
- Очистка расширений браузера, связанных с Antigravity
- Поиск скрытых файлов кэша

**Когда использовать:**
- Когда быстрая очистка не решила проблему
- Перед чистой переустановкой
- При упорных ошибках установки

**Безопасность:** ✅ Безопасно - создаёт резервную копию перед удалением

---

### 3️⃣ Сброс сети
**Что делает:**
- Очистка кэша DNS
- Сброс сетевого стека Windows
- Сброс настроек TCP/IP

**Когда использовать:**
- "Сетевая ошибка" при входе
- Проблемы с таймаутом подключения
- После изменения VPN/прокси

**Безопасность:** ⚠️ Требует перезагрузки - но полностью безопасно

---

### 4️⃣ Полное восстановление
**Что делает:**
- Запускает глубокую очистку (опция 2)
- Затем запускает сброс сети (опция 3)
- Полная очистка системы и исправление сети

**Когда использовать:**
- Нужна максимальная очистка
- Несколько неудачных попыток установки
- Проблемы и с файлами, и с сетью

**Безопасность:** ✅ Безопасно - комбинация двух безопасных операций

---

### 5️⃣ Тестовый режим (Dry Run)
**Что делает:**
- Включает "тестовый режим"
- Показывает, что будет удалено, без фактического удаления
- Позволяет предварительно просмотреть все операции

**Когда использовать:**
- Первое использование инструмента
- Хотите увидеть, что будет очищено
- Тестирование перед фактической очисткой

**Безопасность:** ✅ Полностью безопасно - никаких фактических изменений

---

### 6️⃣ Помощник входа в браузер ⭐ НОВОЕ

**Опция 1: Очистка следов Antigravity в браузере (Безопасно)**
- Сканирует Chrome, Edge, Brave и Firefox
- Находит только cookie/кэш, связанные с Antigravity
- Удаляет застрявшие данные входа
- Автоматическое резервное копирование перед удалением

**Опция 2: Оптимизация сети для входа**
- Очистка кэша DNS
- Тест подключения к сервисам Google
- Исправление конфликтов прокси

**Опция 3: Сетевой диагностический отчёт**
- Тест подключения к серверам Google
- Проверка разрешения DNS
- Обнаружение проблем прокси/VPN
- Проверка SSL-сертификатов

**Опция 4: Полное исправление входа**
- Объединяет опции 1, 2 и 3
- Полное исправление браузера и сети

**Поддерживаемые браузеры:**
- ✅ Google Chrome
- ✅ Microsoft Edge
- ✅ Brave Browser
- ✅ Mozilla Firefox

---

### 7️⃣ Менеджер сессий ⭐ НОВОЕ

**Опция 1: Резервное копирование текущей сессии**
- Сохраняет текущую сессию входа
- Шифрует cookie с помощью AES-256
- Безопасно хранит в `~/.antigravity-cleaner/sessions/`

**Опция 2: Восстановление сохранённой сессии**
- Восстанавливает ранее сохранённую сессию
- Избегает повторного ввода учётных данных
- Автоматический вход

**Опция 3: Список всех сохранённых сессий**
- Показывает все резервные копии сессий
- Отображает возраст и статус сессии

**Опция 4: Удаление старых сессий**
- Удаляет просроченные сессии (старше 30 дней)
- Освобождает дисковое пространство

**Безопасность:**
- 🔒 Шифрование AES-256-GCM
- 🔒 Только локальное хранение (без облака)
- 🔒 Автоматическое истечение через 30 дней
- 🔒 Ограничительные права доступа к файлам
